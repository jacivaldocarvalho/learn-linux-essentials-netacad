### Linux Distributions

A Linux distribution combines the **Linux kernel** with system tools, libraries, applications, and package-management utilities to provide a complete operating system.

Some of the major historical distribution families include:

- Debian
- Red Hat
- Slackware

Different distributions may target different use cases, including desktops, servers, cloud infrastructure, networking, security, and specialized computing.

### Linux Embraces the CLI

Operating systems generally provide two main ways to interact with the system:

- **GUI — Graphical User Interface**
- **CLI — Command Line Interface**

A GUI provides graphical elements such as windows, menus, icons, and buttons.

A CLI provides a text-based interface where instructions are entered as commands.

Linux places significant emphasis on the CLI because it provides:

- precise control;
- efficient system administration;
- fast execution of complex tasks;
- remote administration capabilities;
- automation through shell scripts;
- a relatively consistent working environment across Linux distributions.

A common command structure is:

```text
command [options] [arguments]
```

For example:

```bash
ls -l /etc
```

Where:

```text
ls       command
-l       option
/etc     argument
```

## Key Concepts

| Concept | Description |
| --- | --- |
| Linux | The kernel at the core of a Linux-based operating system |
| Kernel | Core component responsible for managing system resources and hardware |
| GNU | Project responsible for many tools commonly used with Linux |
| Distribution | Linux kernel combined with tools, libraries, applications, and system utilities |
| GUI | Graphical User Interface |
| CLI | Command Line Interface |
| Package | Unit used to distribute software |
| Package Manager | Tool used to install, update, and remove software packages |
